# Glossary

**Tier**: A layout step in the responsive design. The site is designed for the smallest tier first, and each larger tier only adds to it. There are three: **mobile** (the base, under 40em), **tablet** (40em and up), **desktop** (60em and up). The names are labels for width ranges, not detected devices: a narrow desktop window is in the mobile tier.
_Avoid_: base/mid/wide, small/medium/large.

**Measure**: The line length of body text, in characters. It stays about the same in every tier.
